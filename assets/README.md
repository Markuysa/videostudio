# Звуковая библиотека

- `music/` — фоновые треки (mp3/wav/m4a/flac/ogg). Планировщик выбирает трек по тегам и настроению.
- `sfx/` — звуковые эффекты; планировщик расставляет их по сценам (`sfx: [{file, offset, volume}]`).
- `index.json` — индекс с тегами. Создаётся командой `python studio.py assets`; теги и поле `mood`
  можно править руками, при переиндексации они сохраняются.

Имена файлов лучше делать говорящими: `lofi_rain_calm_80bpm.mp3`, `thunder_distant.wav` —
из них собираются теги. Используйте только музыку, на которую у вас есть права.
