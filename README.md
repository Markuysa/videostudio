# AI-киностудия на LTX-2.5

Одна команда: ваш запрос словами → сценарий и раскадровка с оптимизированными промптами →
рендер сцен на GPU RunPod (LTX-2.5, видео + звук) → бесшовная сборка с музыкой, эффектами,
субтитрами и нормализацией громкости → готовый `film.mp4` у вас на диске.

```bash
python studio.py make "Эстетичный шортс: дождливый вечер в Токио, девушка с красным зонтом, лоу-фай" \
    --kind aesthetic --duration 40
```

Форматы: `short` (вертикальный шортс с хуком и субтитрами), `aesthetic` (атмосферное видео под музыку),
`film` (короткий метр с драматургией), `episode` (эпизод сериала по библии персонажей).

## Установка

```bash
cd film_studio
python3 -m venv .venv && .venv/bin/pip install anthropic pytest
cp film_config.example.json film_config.json      # вписать runpod_api_key и network_volume_id
export ANTHROPIC_API_KEY=sk-ant-...                # «мозг» студии; без ключа используется локальная Ollama
brew install ffmpeg                                # только для локальной пересборки (studio assemble)
.venv/bin/python studio.py doctor                  # проверка окружения
```

Для рендера нужен аккаунт RunPod с Network Volume (100+ ГБ) и принятые лицензии на
huggingface.co/Lightricks/LTX-2.5 и LTX-2.5-22b-IC-LoRA-Pixel-Spatial-Upscaler (`hf_token` в конфиге
при первой установке). Модели скачиваются на том один раз (~70 ГБ), дальше каждый рендер стартует за минуту.

## Веб-интерфейс

```bash
.venv/bin/python studio.py ui          # откроет http://127.0.0.1:8765 в браузере
```

Главная: форма «что снимаем» (тип, длительность, формат, качество, музыка, субтитры, сериал) и кнопки
«План и рендер» / «Только план». Задачи выполняются отдельными процессами с живым логом и прогрессом по
сценам; закрытие браузера или сервера рендер не останавливает. Разделы: Планы (сцены, проверка линтером,
правка JSON, рендер, исправление промптов моделью), Фильмы (плеер, таймлайн сцен с пайплайном каждой,
пересборка с другой музыкой/субтитрами, скачивание), Сериалы (библии, эпизоды, заметки о непрерывности),
Звук (загрузка музыки и эффектов), Настройки (диагностика, предпочтения планировщика).

## Команды

| Команда | Что делает |
|---|---|
| `studio.py plan "запрос" [--kind] [--duration] [--format] [--quality] [--music] [--captions]` | составить план: сюжет, стилевая библия, персонажи, сцены с промптами |
| `studio.py make "запрос" ...` | план + рендер + скачивание одной командой |
| `studio.py render plans/x.json [--keep-pod]` | отрендерить готовый план на RunPod |
| `studio.py review plans/x.json [--fix]` | проверить промпты линтером, с `--fix` исправить моделью |
| `studio.py estimate plans/x.json` | хронометраж, время и стоимость рендера |
| `studio.py assemble films/<slug> [--music трек] [--captions]` | пересобрать скачанный фильм локально без GPU |
| `studio.py series new "описание" --name tokyo --episodes 6` | создать библию сериала |
| `studio.py plan "что происходит в серии" --series tokyo` | эпизод по библии (персонажи слово в слово) |
| `studio.py series show/list/note` | посмотреть библию, добавить заметку о непрерывности |
| `studio.py assets` | переиндексировать библиотеку музыки и звуков |
| `studio.py prefs "меньше крупных планов"` | постоянные предпочтения для всех будущих планов |
| `studio.py fetch <slug>` / `cleanup` | забрать фильм с тома / удалить все Pod'ы студии |
| `studio.py ui [--port 8765]` | веб-интерфейс |

`python make_film.py plans/x.json` по-прежнему работает (обёртка над `render`).

## Как устроен план

`plans/<slug>.json` — обычный JSON, его можно править руками перед рендером:

```json
{
 "title": "Я подожду", "kind": "film", "format": "9:16", "quality": "high", "seed": 2026,
 "style": {"visual": "...", "palette": "...", "lighting": "...", "sound": "..."},
 "characters": [{"name": "Старик", "descriptor": "an old fisherman with a wet grey beard and a brass lantern"}],
 "music": {"file": "assets/music/sea_ambient.mp3", "volume": 0.25, "duck": true},
 "captions": {"enabled": false},
 "shots": [
  {"id": "001", "seconds": 8, "transition": "cut", "prompt": "Extreme close-up ... Sound: ..."},
  {"id": "002", "seconds": 8, "transition": "continue", "prompt": "..."},
  {"id": "003", "seconds": 5, "transition": "dissolve", "transition_seconds": 0.6, "prompt": "...",
   "caption": "Он ждал всю ночь", "sfx": [{"file": "assets/sfx/thunder.wav", "offset": 1.2, "volume": 0.7}]}
 ]
}
```

- `transition`: `cut` — монтажная склейка; `continue` — клип начинается с последнего кадра предыдущего
  (один непрерывный дубль длиннее 10 с); `dissolve` — наплыв видео и звука.
- Длительности сами приводятся к сетке LTX (8k+1 кадров при 24 fps). В режиме `high` сцена ≤ 10 с,
  в `fast` ≤ 20 с (длинные клипы генерируются окнами).
- Старые планы версии 1 (`"continue": true`) читаются без изменений.

## Как студия пишет промпты

Планировщик (Claude Opus 5.5 по умолчанию, или локальная Ollama) работает в три прохода: сюжет и
стилевая библия → сцены по актам → линтер + точечные правки. Правила промптинга LTX-2.5 зашиты в
`studio/knowledge.py`: один абзац 70–180 слов в настоящем времени, кадр → персонаж (постоянный
дескриптор вместо имени) → действие → движение камеры → свет → звук и реплики в кавычках, без текста
на экране и без отрицаний. Линтер (`studio/lint.py`) проверяет каждый промпт детерминированно: язык,
длина, камера, звук, свет, списки, местоимения без дескриптора, просьбы нарисовать надписи.

Ваши постоянные пожелания (`studio prefs`), библия сериала и библиотека звуков попадают в системный
промпт, так что промпты оптимизируются именно под ваши запросы и ваш материал.

## Бесшовная сборка

`studio/assemble.py` собирает фильм одним проходом ffmpeg: нормализация клипов, микро-фейды звука на
склейках (нет щелчков), удаление дублирующегося кадра при `continue`, `xfade`/`acrossfade` для наплывов,
музыка лупом с фейдами и приглушением под речь (sidechain), SFX и закадровый голос по таймлайну,
субтитры ASS с безопасной зоной для 9:16, нормализация громкости EBU R128 (−14 LUFS).

Клипы скачиваются вместе с фильмом в `films/<slug>/clips`, поэтому поменять музыку или добавить
субтитры можно без GPU: `studio.py assemble films/<slug> --music assets/music/other.mp3`.

## Рендер на RunPod

`studio/render_remote.py` поднимает Pod (ищет свободные карты из списка, при нехватке 80–96 ГБ карт
через час переключается на `fast`), загружает пакет студии и план, ставит LTX-2.5 (`remote/ltx_studio.sh`),
запускает `remote/film_night.sh` в фоне и ждёт. Pod удаляется автоматически, даже если ноутбук уснул
(`max_hours`). Готовое всегда лежит на томе: `studio.py fetch <slug>`.

`remote/film.py` рендерит каждую сцену с цепочкой откатов: DFR (1080p, детализация) → distilled в том
же разрешении с тем же стартовым кадром → DFR без кадра → быстрый режим. Так решена падавшая у вас
сцена 002 (CUBLAS/illegal memory access в keyframe-декодере DFR с входной картинкой на 193+ кадрах; на 121 кадре проходит при любой силе условия, поэтому планировщик делает сцены-продолжения в `high` не длиннее 5 с, а для длинных сцен со стартовым кадром рендер сразу идёт в distilled 1080p). Готовые клипы кэшируются по
содержимому промпта, перезапуск продолжает с места остановки. В `report.json` видно, каким
пайплайном сделана каждая сцена.

## Озвучка и звук

- Речь и шумы LTX-2.5 генерирует сама по описанию в промпте (реплики в кавычках, голос описан).
- Музыка и SFX — ваша библиотека `assets/music`, `assets/sfx` (см. `assets/README.md`). Без треков
  план всё равно сохранит `music.mood`, трек можно добавить позже и пересобрать.
- Закадровый голос: поле `narration` в сцене + ElevenLabs (`elevenlabs_api_key`, `elevenlabs_voice_id`).
  Файлы генерируются перед рендером и уезжают на Pod вместе с планом.

## Тесты

```bash
.venv/bin/python -m pytest -q tests
```

Проверяют схему плана и сетку кадров, линтер, граф фильтров ffmpeg и реальную сборку синтетических
клипов, планировщик с фиктивной LLM, полный прогон `remote/film.py` с имитацией LTX (включая откат
после CUDA-ошибки и кэш), CLI.

## Структура

```
studio.py            CLI
studio/              пакет (едет на Pod вместе с планом)
  schema.py          план, валидация, сетка кадров
  knowledge.py       правила промптинга LTX-2.5, пресеты форматов
  planner.py         LLM-планировщик (outline -> shots -> lint -> revise)
  lint.py            детерминированный линтер промптов
  llm.py             провайдеры: Anthropic SDK, Ollama, Fake для тестов
  bible.py           библия сериала
  audio.py           библиотека музыки/SFX, TTS
  assemble.py        сборка ffmpeg
  render_remote.py   RunPod: Pod, загрузка, ожидание, скачивание
  ui.py, jobs.py     веб-интерфейс (HTTP API + фоновые задачи), web/ — страница
remote/              pod-сторона: ltx_studio.sh (установка + веб-интерфейс), film.py, film_night.sh
plans/ films/ series/ assets/
```
